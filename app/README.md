# Task Management App

This web application is a task management tool built using React.js. It allows users to create, edit, delete, and mark tasks as completed, along with features like a trash bin, settings, and a user profile.

## Features

* Login:* Secure login page to authenticate users.
* Dashboard:* Displays key statistics:
    - Total Tasks
    - Pending Tasks
    - Completed Tasks
    - Expired Tasks
* Task Manager:*
    - Add tasks with name, description, and due date.
    - Edit existing tasks.
    - Delete tasks (with option to view in Trash).
    - Mark tasks as completed with visual indication.
* Trash:* View and potentially restore deleted tasks.
* Settings:*
    - Choose from 4 different fonts.
    - Toggle dark mode.
* Profile:*
    - View user profile information.
    - Update profile details.
    - Delete user account.
